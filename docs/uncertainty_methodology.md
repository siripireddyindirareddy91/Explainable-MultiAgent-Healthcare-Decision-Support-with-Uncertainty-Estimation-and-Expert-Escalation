# Uncertainty methodology

Five quality dimensions are transformed consistently into weighted deficits: completeness 20%, evidence quality 25%, agreement 20%, calibration quality 20%, input reliability 15%. Components and individual contributions are included in API output and the interface. Higher final values mean less reliable context, independently of clinical risk.

Completeness measures nine fields: symptoms, history, medications, allergies, duration, heart rate, systolic pressure, oxygen saturation and temperature. Explicit `none` counts as recorded. Evidence quality is a passage-count proxy, not a clinical truth assessment. Agreement measures configured contradictions, not independent ensemble disagreement. Input reliability is a basic age check. Calibration is unavailable and conservatively zero. The score is a transparent teaching heuristic and not a clinical probability.
